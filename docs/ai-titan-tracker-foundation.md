# AI Titan Tracker 基礎ドキュメント

## 1. アプリ企画書

### プロジェクト名
AI Titan Tracker（仮）

### 背景と課題
AI技術とトレンドの進化は日進月歩であり、情報のキャッチアップが非常に困難です。特に、サム・アルトマン（OpenAI）などのAI業界の重鎮の発言や、長時間のポッドキャスト・インタビュー動画には重要な示唆が含まれている一方で、すべてを視聴する時間的余裕があるビジネスパーソンやエンジニアは限られています。

### ターゲットユーザー
- 最新のAIトレンドをビジネスに活かしたい経営者・企画担当者
- 技術動向を追いたいAIエンジニア・クリエイター
- 長時間動画を見る時間はないが、要点を短時間で把握したいタイパ重視層

### コア・バリュー（提供価値）
**「1日5分で、世界のAIの頭脳とシンクロする。」**

情報収集から要約、動画ハイライト抽出までをAIが自動化し、ユーザーは「読むだけ」「見るだけ」で本質を把握できる体験を提供します。

### 主な機能
1. **タイタン・フィード**
   - 指定したAI重鎮（サム・アルトマン、ヤン・ルカン等）の最新発言、X（旧Twitter）投稿、公式ブログを3行要約で配信。
2. **動画ハイライト（切り抜き）**
   - 長時間インタビュー動画から重要発言シーンをAIが特定し、ショート視聴可能なハイライト情報（タイムスタンプ＋要約）を提供。
3. **パーソナライズAIニュース**
   - 一般AIニュースをユーザー関心に合わせて重要度スコアリングし、優先度の高い順で提示。

## 2. 要件定義（ハイレベル）

### システム構成・推奨技術
- **フロントエンド**: Flutter または React Native（iOS/Android両対応）
- **バックエンド / DB**: Firebase または Supabase
- **データ収集・AI処理（バッチ）**: Python + Google Cloud Run または AWS Lambda
- **利用API**:
  - 動画解析・要約: Gemini 1.5 Pro API
  - テキスト要約: OpenAI API（GPT-4o）
  - データ取得: YouTube Data API / RSS / Webスクレイピング（Perplexity API等）

### 機能要件
#### コンテンツ自動生成機能（バックエンド）
- 毎日定時で対象YouTubeチャンネル、ブログ、ニュースサイトの最新データを収集。
- 収集データをAI APIに渡し、要約・タグ付け・重要度スコアリングを実行。
- 動画データはハイライト用タイムスタンプを抽出し、アプリ側で該当位置から再生可能にする。

#### ユーザー向け機能（フロントエンド）
- **タイムライン表示**: 最新要約記事と動画ハイライトを時系列／重要度順で表示。
- **動画プレイヤー**: YouTube Iframe APIで、指定タイムスタンプから再生。
- **お気に入り/保存**: 後で読み返すためのブックマーク機能。
- **人物フィルタリング**: 特定人物（サム・アルトマン、デミス・ハサビス等）に絞り込み。

### 非機能要件
- バッチ処理は最低1日2回（朝・夕）実行し、情報鮮度を維持。
- 著作権配慮のため動画本体は自社保存せず、YouTube公式埋め込み再生を利用。

## 4. 次ステップ推奨

初期フェーズでは、**バックエンド（情報収集・要約パイプライン）から着手**することを推奨します。

### 推奨理由
- プロダクト価値の根幹は「情報の質と鮮度」であり、まずデータ生成基盤の信頼性を固めるべき。
- フロントエンドは、スキーマとAPIレスポンス形が安定してから実装すると手戻りが減る。
- MVPでは「まず読める・再生できる」状態を作ることで、ユーザーテストが早く回せる。

### 直近2週間の実行プラン（MVP）
1. Supabaseのテーブル作成（feeds, contents, persons, highlights, bookmarks）。
2. Cloud Run/Lambdaで収集ジョブ（YouTube/RSS）を実装。
3. OpenAI/Gemini連携で要約＋ハイライト抽出を実装。
4. フロントでタイムライン一覧＋詳細＋人物フィルタを最小実装。
5. 朝夕バッチ運用とログ監視（失敗通知）を実装。
